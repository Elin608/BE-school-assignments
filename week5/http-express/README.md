# HTTP Express API

My first Express API built with typeScript

## Routes

### GET /
Returns a welcome message.
**Status:** `200 OK`
![Home route](images/home.PNG)

### GET /gallery
Returns the street art gallery. 
**Status:** `200 OK`
![Gallery route](images/gallery.PNG)

### GET /featured
Returns the featured artwork. 
**Status:** `200 OK`
![Featured route](images/featured.PNG)

### GET /about
Returns information about the Street Art API 
**Status:** `200 OK`
![About route](images/about.PNG)

### GET /maintenance 
Returns a maintenance message. 
**Status:** `503 Service Unavailable`
![Maintenance route](images/maintenance.PNG)
